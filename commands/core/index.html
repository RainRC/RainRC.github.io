    对话与上下文¶

    插件 builtin_commands 版本 0.0.1 作者 Soulter

    管理对话上下文、查看用量与面板运维

    这些指令由 AstrBot 内置插件提供，任何会话都能使用。它们负责上下文管理（新建/清空对话）、帮助查询、会话变量以及面板运维，不依赖任何游戏插件。

    指令一览¶

    本插件共注册 10 条指令，点击指令即可复制。

    指令 别名 权限 说明
    /dashboard_update — 管理员 更新 AstrBot 面板（WebUI）
    /name — 管理员 设置当前会话的显示名称
    /new — 群管理员 创建一个新对话（清空当前上下文）
    /provider — 管理员 查看或切换大模型服务商
    /reset — 群管理员 清空当前对话的上下文
    /set — 所有人 设置会话变量
    /sid — 所有人 获取当前会话 ID 等相关信息
    /stats — 所有人 查看当前对话的 Token 用量统计
    /stop — 所有人 停止 Agent 正在执行的任务
    /unset — 所有人 取消会话变量

    使用要点¶

    • 群聊里如果上下文串味了，用 /new 开一个新对话；/reset 效果相同但需要群管理员身份。
    • /stats 查看当前对话累计消耗的 Token，方便控制成本。
    • /stop 可以立刻中断机器人正在生成的长回复。
    • 标有 👑 的指令只有机器人管理员可用（在 AstrBot 面板 admins_id 中配置）。
